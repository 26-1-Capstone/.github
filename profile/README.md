## 🎯 프로젝트 소개


### 핵심 기능
- 공동구매 
- 장바구니 담기 및 주문/결제 시스템
- 리뷰 작성 및 조회
- JWT 기반 사용자 인증 (회원가입/로그인/로그아웃)
- 관리자 물품 등록/삭제 및 이미지 관리 (AWS S3)
- **Android, iOS, 데스크탑** 모두에서 사용 가능 – 크로스플랫폼 지원
